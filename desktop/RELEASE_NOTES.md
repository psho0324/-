Windows 10/11 64비트용 내 플래너 v0.1.1 테스트 버전입니다.

- 할 일·목표의 빈 제목 안내, 카테고리 편집·삭제 및 신규 카테고리 취소 처리를 보완했습니다. 설정과 창 제목에서 실행 중인 버전을 확인할 수 있습니다.
- 백업 충돌·손상 복구·저장 실패 처리와 입력 날짜/시간·완료 표시·통계·좁은 화면 오류를 보완했습니다. 실행 엔진을 Electron 45.3.0으로 갱신했습니다.
- 새 버전을 자동 확인·다운로드하고 설정의 ‘설치하고 다시 시작’을 누르면 저장과 로컬 백업을 확인한 뒤 갱신합니다. 일반 종료만으로 설치하지 않습니다.
- **0.1.0에는 자동 업데이트가 없으므로 이번 버전은 한 번 직접 설치해야 합니다.** 이후 버전부터 앱 내 갱신을 사용할 수 있습니다.

다운로드: `MyPlanner-Setup.exe`. 검증용 SHA-256은 `SHA256SUMS.txt`에 있습니다. `latest.yml`과 blockmap은 앱 업데이트용 파일입니다.

코드 서명이 없어 Windows SmartScreen에 ‘Windows의 PC 보호’와 ‘알 수 없는 게시자’가 표시될 수 있습니다. 이 저장소에서 받은 파일인지 확인하고 출처를 신뢰할 때만 ‘추가 정보 → 실행’을 선택하세요. 자동 업데이트가 이 경고를 없애지는 않습니다.

모든 Windows 자동 검사가 통과한 태그 빌드만 공개하도록 구성했습니다. 검사 결과는 `installed.json`, `update-e2e.json`에서 확인합니다. 알림 표시·클릭, 트레이 조작, Windows 로그인·종료, 실제 클라우드 폴더는 별도 수동 확인 대상입니다.

기존 데이터 저장 위치를 유지하며 앱 제거 시 데이터를 자동 삭제하지 않습니다. 기존 앱의 설정에서 백업을 내보내고 앱을 완전히 종료한 뒤 이번 설치 파일을 실행해 주세요. 설치 후 설정의 ‘현재 버전’에서 v0.1.1을 확인할 수 있습니다. 코드 서명·Microsoft Store 배포·모바일 앱·계정 동기화는 포함하지 않습니다.
