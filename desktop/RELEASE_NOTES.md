Windows 10/11 64비트용 내 플래너 v0.1.5 테스트 버전입니다.

- 로그인 완료 화면에 큰 ‘플래너로 돌아가기’ 버튼을 추가했습니다. 설치된 앱을 여는 고정 링크이며 인증 정보는 담지 않습니다. 브라우저가 외부 앱 열기를 물으면 ‘열기’를 선택해 주세요.
- 숨김·최소화 상태의 기존 플래너 창으로 돌아오도록 보완했습니다. Windows가 창 전환을 거부하면 작업 표시줄에 알립니다. 브라우저 정책에 따라 앱 전환 확인이 필요하며 탭 자동 닫힘은 보장하지 않습니다.
- 연속 로그인에서 이전 시도의 미리 열린 연결 때문에 다음 로그인이 실패할 수 있는 문제를 수정했습니다. 전송 중인 성공·실패 응답은 끝까지 보내며 기존 인증 검증은 유지합니다.
- 일반 서버 실패는 재시도와 지속 실패 시 운영자 연락을 안내합니다. 명확한 Google 설정 오류와 사용자 취소는 따로 구분하며 서버 원문·토큰·인증 코드를 화면에 표시하지 않습니다.
- Windows 설치·업데이트에서 앱 열기 연결을 등록하고, 삭제할 때는 자기 연결만 제거합니다. URL 앞에 옵션 구분자를 넣고, 앱 시작 시 다른 설치 범위의 연결을 덮어쓰지 않도록 정리했습니다.
- 실제 Windows 설치·업데이트·데이터 보존·삭제·다른 소유자의 연결 보존 검사와 로그인 화면 검사를 보강했습니다. 검사 도구는 설치 앱에 포함하지 않습니다.

기존 일정·할 일·목표·자료 폴더·백업·계정 동기화·오프라인 알림과 데이터 저장 형식은 유지합니다. 개인 일정이나 실제 인증 정보는 설치 파일에 포함하지 않습니다.

실제 Google 로그인과 사용자 PC의 Edge·Chrome 복귀, 두 PC 동기화는 배포 후 사용자가 확인합니다. 새 프로토콜 구분자를 사용하는 수동 Edge 진단은 이번 일반 배포 검사에서 실행하지 않았습니다. 서버의 실제 OAuth 설정 문제는 앱 안내 변경만으로 해결되지 않습니다. 이메일 인증번호 발송과 모바일 앱은 이번 변경의 검증 대상에 포함하지 않습니다.

0.1.1의 자동 업데이트 경로를 유지합니다. 공개된 새 버전을 내려받은 뒤 설정의 ‘설치하고 다시 시작’으로 저장·백업을 확인하고 설치합니다. 일반 종료만으로 설치하지 않습니다. 0.1.0은 자동 업데이트가 없어 직접 설치가 필요합니다.

코드 서명은 없어 Windows SmartScreen 경고가 표시될 수 있습니다. 자동 업데이트가 경고를 없애지는 않습니다. 다운로드는 MyPlanner-Setup.exe이며 SHA256SUMS.txt로 파일을 확인할 수 있습니다.

2026-11-21 사용자가 v0.1.5 배포를 명시적으로 승인했습니다. 이 승인은 이번 버전에 한정하며 이후 배포도 사용자가 확인하고 승인한 뒤에만 진행합니다. 태그 빌드의 필수 검사와 실제 공개 자산 검증 후 홈페이지 다운로드 버전을 갱신합니다. 알림 외관·클릭, 트레이 실제 표시, Windows 로그인 자동 시작, 실제 클라우드 폴더 전송은 별도 수동 확인 대상입니다.
