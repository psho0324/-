Windows 10/11 64비트용 내 플래너 v0.1.4 테스트 버전입니다.

- Google 로그인 실패 시 취소·설정/서버 오류·기타 실패의 안내를 구분합니다. 서버 원문·인증 코드·토큰을 안내에 표시하지 않습니다.
- 실패 뒤 로그인 대기를 끝내고 다시 시도할 수 있도록 했습니다. 아주 빠른 재시도에서 이전 콜백 연결이 재사용되는 문제도 보완했습니다.
- Google 로그인에 성공해 세션을 저장하면 기존 플래너 창을 복원하고 앞으로 가져오도록 연결했습니다. 일반 인증 상태 변경·로그인 실패·토큰 갱신에서는 포커스를 바꾸지 않습니다.
- 로그인 완료 페이지에서 주소의 인증 코드·state·fragment를 지우고 탭 닫기를 시도합니다. Edge·Chrome의 보안 정책이 자동 닫기를 제한하면 완료 안내가 남습니다. 외부 브라우저 탭이 항상 자동으로 닫힌다고 보장하지 않습니다.
- 로그인 없는 사용, 기존 자료 폴더·백업·계정 동기화·로컬 알림과 고정 다운로드 주소를 유지합니다. 저장 형식과 동기화 SQL·목표 모델은 변경하지 않았습니다.

사용자는 인증 설정 수정 후 0.1.3에서 Google 로그인 완료 화면을 확인했습니다. 이번 버전의 실제 Windows·외부 브라우저 복귀와 탭 닫기, 서로 다른 두 PC의 동기화는 추가 수동 확인 대상입니다. 로컬 검사에서는 가짜 인증 공급자와 임시 자료로 실패 안내·성공 페이지·안전한 재시도를 검증했습니다. 실제 Google Client Secret 설정 오류는 운영 설정에서 확인해야 하며 앱의 안내 수정만으로 해결되지 않습니다. Google 인증은 현재 등록된 테스트 사용자로 제한됩니다. 이메일 인증번호 발송과 모바일 앱은 이번 변경에 포함하지 않습니다.

0.1.1의 자동 업데이트 경로를 유지합니다. 공개된 새 버전을 내려받은 뒤 설정의 ‘설치하고 다시 시작’으로 저장·백업을 확인하고 설치합니다. 일반 종료만으로 설치하지 않습니다. 0.1.0은 자동 업데이트가 없어 직접 설치가 필요합니다.

코드 서명은 없어 Windows SmartScreen 경고가 표시될 수 있습니다. 자동 업데이트가 경고를 없애지는 않습니다. 다운로드는 MyPlanner-Setup.exe이며 SHA256SUMS.txt로 파일을 확인할 수 있습니다.

모든 배포는 사용자가 확인하고 승인한 뒤에만 진행한다. 검사 결과와 변경 내용을 먼저 보고하고 사용자가 “배포해”라고 말한 뒤에만 main 병합·버전 올리기·태그 푸시·Release 공개·홈페이지 다운로드 버전 변경을 진행합니다. Windows 자동 검사 통과도 필수이며, 검사 통과만으로 배포하지 않습니다. 알림 외관·클릭, 트레이 실제 표시, Windows 로그인 자동 시작, 실제 클라우드 폴더 전송은 별도 수동 확인 대상입니다. 기존 앱에서 백업을 내보내고 설치 후 설정의 실제 버전을 확인해 주세요.
