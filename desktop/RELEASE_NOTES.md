Windows 10/11 64비트용 내 플래너 v0.1.3 테스트 버전입니다.

- 로그인 없이 사용하는 기존 방식과 자료 폴더를 유지합니다. 일정·할 일·목표와 기기 백업은 인터넷 없이 사용할 수 있습니다.
- 설정에 선택적 Google 로그인과 계정 동기화를 추가했습니다. 로그인만으로 업로드하지 않으며, 자료 연결에 동의하면 먼저 저장·백업한 뒤 연결합니다. 연결 전의 기기 자료도 따로 보관합니다.
- 연결한 계정에서는 오프라인 변경을 기기에 먼저 저장하고, 인터넷이 가능해지면 항목별 변경과 삭제를 자동으로 맞춥니다. 기기별 자동 시작·트레이·저장 위치 설정은 동기화하지 않습니다. 두 기기의 겹친 수정은 별도 충돌 사본으로 보존합니다.
- 로컬 일정 알림의 재실행 중복·절전 복귀·재시도를 보완했습니다. 알림에 인터넷은 필요하지 않지만 앱 또는 트레이 프로세스가 실행 중이어야 합니다.
- 0.1.2에 빠졌던 업데이트 준비 알림·트레이 설치 메뉴·시작 실패 복구 안내와 릴리스 파일 검증을 포함했습니다. 준비 알림은 이 버전을 설치한 뒤 다음 업데이트부터 동작합니다.
- 테마·상세 추가창·정확한 시간 입력·반복 목표와 실천 기록은 0.1.2의 기능을 유지합니다.

Google 실제 로그인, Windows 세션 암호화, 서로 다른 두 PC의 동기화는 이번 공개 후 사용자가 직접 확인할 항목입니다. 자동 검사 통과를 실제 서비스 연결 성공으로 해석하지 않습니다. 처음에는 예시 할 일로 확인하고 기존 개인 자료는 별도 백업해 주세요. Google 인증은 현재 등록된 테스트 사용자로 제한됩니다. 이메일 인증번호 발송 설정은 아직 실사용 검증하지 않았습니다. 모바일 앱은 이번 버전에 포함하지 않습니다.

0.1.1의 자동 업데이트 경로를 유지합니다. 공개된 새 버전을 내려받은 뒤 설정의 ‘설치하고 다시 시작’으로 저장·백업을 확인하고 설치합니다. 일반 종료만으로 설치하지 않습니다. 0.1.0은 자동 업데이트가 없어 직접 설치가 필요합니다.

코드 서명은 없어 Windows SmartScreen 경고가 표시될 수 있습니다. 자동 업데이트가 경고를 없애지는 않습니다. 다운로드는 MyPlanner-Setup.exe이며 SHA256SUMS.txt로 파일을 확인할 수 있습니다.

모든 배포는 사용자가 확인하고 승인한 뒤에만 진행한다. 검사 결과와 변경 내용을 먼저 보고하고 사용자가 “배포해”라고 말한 뒤에만 main 병합·버전 올리기·태그 푸시·Release 공개·홈페이지 다운로드 버전 변경을 진행합니다. Windows 자동 검사 통과도 필수이며, 검사 통과만으로 배포하지 않습니다. 알림 외관·클릭, 트레이 실제 표시, Windows 로그인 자동 시작, 실제 클라우드 폴더 전송은 별도 수동 확인 대상입니다. 기존 앱에서 백업을 내보내고 설치 후 설정의 실제 버전을 확인해 주세요.
