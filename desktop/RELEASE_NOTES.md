Windows 10/11 64비트용 내 플래너 v0.1.2 테스트 버전입니다.

- 설정에서 다크·라이트·시스템 테마를 선택하고 재실행 후에도 유지합니다.
- 할 일·목표는 추가 버튼을 누르면 상세 작성창을 엽니다. 상단은 검색으로 바꾸고 우선순위의 의미를 표시했습니다. 신규 할 일의 목표 연결 선택은 제거하되 기존 연결은 보존합니다.
- 빠른 추가의 2시간짜리·시간/분 합산·자정 통과 입력을 개선했습니다. 시각만 입력한 일정에 임의의 한 시간을 붙이지 않습니다. 입력 충돌은 저장 전에 안내합니다.
- 반복 목표를 날짜별 실천형과 주·월 횟수형으로 구분합니다. 주간·월간 기록, 명시적 못함·미기록, 유사 목표 안내, 사용자가 선택하는 실천 기록 공유를 추가했습니다.
- 기존 자료를 보존하고 새 실천 기록도 백업·복원합니다. 반복 조건을 편집하면 다음 날부터 적용해 과거 기준을 유지합니다.

0.1.1의 자동 업데이트 경로를 유지합니다. 공개된 새 버전을 내려받은 뒤 설정의 ‘설치하고 다시 시작’으로 저장·백업을 확인하고 설치합니다. 일반 종료만으로 설치하지 않습니다. 0.1.0은 자동 업데이트가 없어 직접 설치가 필요합니다.

코드 서명은 없어 Windows SmartScreen 경고가 표시될 수 있습니다. 자동 업데이트가 경고를 없애지는 않습니다. 다운로드는 MyPlanner-Setup.exe이며 SHA256SUMS.txt로 파일을 확인할 수 있습니다.

Windows 자동 검사를 통과한 태그 빌드만 공개합니다. 알림 외관·클릭, 트레이 실제 표시, Windows 로그인 자동 시작, 실제 클라우드 폴더 전송은 별도 수동 확인 대상입니다. 기존 앱에서 백업을 내보내고 설치 후 설정의 실제 버전을 확인해 주세요.
