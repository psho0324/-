# 내 플래너 0.1.2 개발 후보

확인일: 2026-11-12 (한국 시간). 공개 0.1.1에서 시작한 변경이며, 이 문서는 새 버전이 공개됐다는 의미가 아닙니다. main 병합, 버전 태그, Release 공개는 별도로 진행합니다.

## 변경한 사용 흐름

- 설정 → 화면에서 시스템 / 라이트 / 다크 선택. 기본 시스템, 재실행 유지. 초기 화면·작성창·입력·오류 안내도 최종 적용 테마를 따릅니다.
- 할 일·목표의 상단 입력은 해당 화면 검색입니다. 추가 버튼으로 상세 창을 열고 저장할 때 생성합니다. 이름만 필수이며 취소·Esc는 생성하지 않습니다. 검색과 목록 필터 때문에 새 항목이 숨지 않게 생성 후 표시 범위를 조정합니다.
- 할 일의 신규 목표 연결 선택을 제거했습니다. 기존 연결은 편집·재시작·백업에서 유지합니다. 할 일 메뉴는 유지하고 마감일·완료 중심으로 구분합니다. 전체 목록에는 밀린 할 일도 포함합니다.
- 우선순위를 색 점 외에 ‘우선순위: 보통’처럼 텍스트로 표시합니다.
- 빠른 추가는 `9시 수업 2시간`, `2시간짜리`, `2시간 짜리`, `1시간 30분`, `1시간 반`을 해석합니다. 시각만 입력하면 종료 없는 일정으로, 기간을 입력하면 실제 시작·종료로 저장합니다. 자정 통과 범위를 다음 날로 계산합니다. 모순된 범위·길이와 유실될 입력은 저장 전에 안내합니다.
- 기존 오전/오후 추정 규칙은 유지합니다. `HH:mm`은 명시적 24시간제이며 해석 결과를 미리보기에서 확인할 수 있습니다.

## 반복 목표

- 일회성 기존 목표의 연결된 할 일과 진행률은 보존합니다. 새 일회성 목표는 완료 기준을 적고 수동으로 완료 처리합니다.
- 날짜별 실천: 시작·종료일과 예정 요일 기준. 동일 날짜에 여러 건이 있어도 하루 완료로 계산합니다. 과거 미기록과 명시적으로 선택한 못함을 구분합니다. 오늘 미기록은 진행 중이며 분모에서 제외하고, 오늘 완료 또는 못함을 직접 기록한 경우 분모에 포함합니다. 미래와 비대상 날짜는 제외합니다.
- 횟수 달성: 매주 또는 매월의 목표 횟수 대비 실천 건수. 사용자가 추가한 별도 기록은 같은 날이어도 각각 셉니다. 초과 실적은 실제 횟수와 퍼센트로 보존하고 막대만 100%로 제한합니다.
- 주/월 보기는 기록 달력의 범위입니다. 주 3회 목표를 월 보기로 바꿔도 월 목표로 임의 환산하지 않습니다. 월간 실천 건수와 ‘이번 주 목표’ 진행률을 함께 표시합니다.
- 이름의 높은 유사도와 기간 겹침으로 보조 안내를 표시합니다. 같은 키워드만으로 차단하거나 자동 병합하지 않습니다. 기존 목표 정보도 작성창 안에서 확인할 수 있습니다.
- 기록 공유는 사용자가 같은 활동을 선택했을 때만 적용합니다. 실천 원본은 한 건이며 여러 목표가 평가합니다. 전체 실천 건수는 기록 ID 기준 한 번만 셉니다. 공유 기록을 취소하면 연결 목표들에도 반영되고 실행 취소가 가능합니다.
- 기존 반복 목표의 조건·기간·연결 수정은 다음 날부터 적용합니다. 정책 이력으로 지난 날짜의 조건을 보존합니다. 목표 유형 변경은 기존 목표를 덮어쓰지 않고 새 목표로 작성합니다.

## 데이터 보존

기존 planner-data.json 구조에 goalRecords(활동 기록), goalDays(명시적인 못함), 목표별 반복 조건·정책 이력을 추가합니다. 기존 일정·할 일·카테고리·목표·연결·저장 경로는 유지합니다. 시각만 일정은 timeType:point, start=end로 구분하며, 기존 한 시간짜리 일정은 자동 변환하지 않습니다. 0.1.1은 새 실천 자료를 이해하지 못하므로 구버전으로 돌아가기 전에는 0.1.2의 JSON 백업을 별도로 보관해야 합니다. 백업 내보내기·가져오기·실행 취소·자동 백업·폴더 이동도 새 배열을 보존합니다. 잘못된 실천 백업 형식은 기존 데이터를 덮어쓰기 전에 안내합니다.

## 검증 상태

- Node: 기존 검사와 새 테마 11개·목표 모델 33개·빠른 추가 73개 통과.
- 실제 CSP Chromium: 테마/작성/검색/시간/반복/공유/백업/모바일 회귀 검사 통과. 최종 개수는 실행 로그를 기준으로 확인합니다.
- Linux/Xvfb 실제 Electron 45.3.0, 소스 0.1.2: 작성 취소·저장·재실행·트레이 숨김·단일 실행·백업·쓰기 오류/재시도 등 13개 통과.
- Windows 설치 파일 빌드·설치·설치 후 검사·실제 업데이트 검사는 전용 브랜치의 Actions에서 수행하며, 결과 확인 전까지 성공으로 단정하지 않습니다.
- Windows 알림의 실제 외관·클릭, Windows 로그인 자동 시작, 실제 OneDrive 등의 전송은 사용자 PC 수동 확인 항목입니다. 테스트는 격리된 프로필과 가짜 자료만 사용합니다.
